ZUSCHNITT-OPTIMIERER – PWA-Paket

1. ZIP entpacken.
2. Alle enthaltenen Dateien und den Ordner icons in ein GitHub-Repository hochladen.
3. GitHub: Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. Die veröffentlichte HTTPS-Adresse auf Android in Chrome öffnen.
5. Chrome-Menü > App installieren / Zum Startbildschirm hinzufügen.

Für eine APK: Die HTTPS-Adresse anschließend in https://www.pwabuilder.com/ eingeben
und den Android-Paket-Workflow starten. Die PWA lässt sich auch ohne APK direkt installieren.
